# Synthetic test inputs

These fixtures were authored for dots tests. They depict a simple rectangular layout, not a real venue, and do not derive from the excluded research corpus.

- `plan.png`: 2400 × 1600 pixels, for image downscaling and parser detail crops.
- `plan.pdf`: one 600 × 400 point page containing simple stroked rectangles/lines, for PDF page selection and crop rendering.

The unrelated perspective illustration at `apps/web/public/examples/perspective-plan.svg` was authored for the input guide and pitch. It replaces an evaluation-only image in the input guide and pitch.
